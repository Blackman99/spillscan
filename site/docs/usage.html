HOMEDOCSBLOG

Usage

spillscan paths          # list transcript roots
spillscan scan           # exit 2 if findings
spillscan scan --json
spillscan redact         # dry-run
spillscan redact --write # .bak then [REDACTED:<rule>]
spillscan guard          # PreToolUse stdin JSON → decision
spillscan mcp            # read-only MCP: scan_report, list_paths

Pass explicit paths to limit scope: spillscan scan ~/.claude/projects/foo
