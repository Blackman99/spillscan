Agent 早就把密钥打进会话记录了——然后呢？

2026-10-13，有人在 Claude Code 里跑了一句复合 Bash：echo "searching..."; env 2>/dev/null; npm search foo，大约 10 个真实 token 被写进了 ~/.claude/projects/**/*.jsonl。前缀拒绝规则拦不住中间那段；产品侧对 Bash 的 PostToolUse 改写也被忽略。密钥只能去各平台轮换，转录里却还留着副本。

spillscan 是污染巡测仪：一个静态二进制，自动发现 Claude Code / Codex / Cursor 等本地转录根目录，用模式匹配常见云密钥，并能在保持 JSONL 每行合法 JSON 的前提下只改写密钥子串（先写 .bak）。另有一个 PreToolUse guard，在下一次 env 倾倒前直接拒绝。

它不是网络防火墙。它是有人已经打开药瓶之后，你拿来扫房间的那块表。
