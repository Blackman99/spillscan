Tell you, in one command, which secrets already spilled into your local AI coding-agent session transcripts — and scrub them in place with a backup.

01 · Why the meter clicks

A bare env / printenv / cat .env inside an agent Bash call writes live credentials into plaintext JSONL under ~/.claude/projects, ~/.codex/sessions, Cursor, and friends. Prefix deny rules miss echo x; env; npm …. Nothing tells you which sessions still hold which keys — or scrubs them.

Source thread: anthropics/claude-code#80153.

02 · Install

go install github.com/Blackman99/spillscan/cmd/spillscan@latest

No Go toolchain? Static binary for macOS / Linux:

V=0.1.0; OS=$(uname -s | tr A-Z a-z); ARCH=$(uname -m | sed 's/x86_64/amd64/;s/aarch64/arm64/')
curl -fsSL "https://github.com/Blackman99/spillscan/releases/download/v$V/spillscan_${V}_${OS}_${ARCH}.tar.gz" | tar xz spillscan
sudo mv spillscan /usr/local/bin/ && spillscan version

03 · One sweep

$ spillscan scan
SPILLSCAN  files=41 findings=3 distinct=3  2026-10-14 10:04 CST
RULE        PREVIEW    AGENT        FILE:LINE
aws-akia    AKIA…MPLE  claude-code  ~/.claude/projects/…/x.jsonl:128
github-pat  ghp_…a91F  claude-code  ~/.claude/projects/…/x.jsonl:128
openai-sk   sk-p…9Qx2  codex        ~/.codex/sessions/…/y.jsonl:44

CONTAMINATED — 3 distinct secrets in 2 files.
  1. Rotate them at the provider first — scrubbing a transcript does not revoke a key.
  2. Preview the scrub:  spillscan redact
  3. Apply it (.bak kept): spillscan redact --write
$ spillscan redact --write
REDACT (write)  files=2 replaced=3
  bak ~/.claude/projects/…/x.jsonl.bak
  bak ~/.codex/sessions/…/y.jsonl.bak
SCRUBBED — 3 secrets replaced with [REDACTED:<rule>]. Verify: spillscan scan

04 · Guard the next dump

Claude Code PreToolUse hook — deny env-dump class Bash even in compound commands:

# .claude/settings.json
{
  "hooks": {
    "PreToolUse": [{
      "matcher": "Bash",
      "hooks": [{ "type": "command", "command": "spillscan guard" }]
    }]
  }
}

05 · Not a firewall — the cleanup

spillscan = pattern + entropy detection for unknown secrets + JSONL-safe in-place redact. Stroq matches known local values and deliberately does not change past records. gitleaks can scan a directory but is not transcript-aware. Use the meter after the spill; install the guard before the next one.
